# Recipe Explorer
### A multi-page web application built with React, JavaScript, and CSS that allows users to search and explore different recipes.
### Features: 
- Advanced Search: Get recipes by recipe name.
- Fixed Navigation: A persistent top navbar that links to all pages.
- Favorites: Favorites are saved between uses
